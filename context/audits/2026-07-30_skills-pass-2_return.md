**Where the guidance CAUTIONS — candidates for a future ruled pass (NOT executed here; each would need its own census-protected charge):**
1. **Over-constraint audit.** For Claude-5-generation models, dense prohibitive-rule lists and cross-layer instruction repetition are now named anti-patterns (they tax every request via conflict-resolution).
