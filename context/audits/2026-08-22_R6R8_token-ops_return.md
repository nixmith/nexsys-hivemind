## §2 — the invariants as shipped

1. **Request-file consumption order (under `writeLock`):** `exists?` → `readAllLines` → **`Files.delete` FIRST** → execute line-by-line. Unreadable → WARN, zero report, file LEFT (never bricks startup). Undeletable → WARN, zero report, NOTHING executes (fail closed). Pinned: `operatorRequestRotateIsConsumedOnce` (file gone + second pass zero), `operatorRequestUndeletableFileExecutesNothing`, `operatorRequestUnreadableFileExecutesNothing` (both POSIX + non-root `Assumptions`-gated).
2. **`rotate` leaves exactly one active token and deletes nothing:** mint the new record (put) → revoke every other non-revoked entry (`entrySet().setValue`, skipping the new hash) → ONE `persist()` → `writeArtifact(raw)`. Mint-before-revoke so a concurrent `validate()` never sees zero active tokens. Pinned: `rotateRevokesEveryOtherActiveToken` (3 rows, 2 revoked, reopen-stable), `rotateWritesTheArtifact`.
3. **No hash, no raw token on any read surface:** `summaries()` (pinned by `summariesNeverExposeHashes`: no `[0-9a-f]{64}`, no raw token in `toString()`), the list body (pinned: serialized body has no 64-hex run, no 43-char base64url run), the audit line (key ids only — pinned: no 43-char/64-hex run, no display name), the `skipped` entries (`line N: <reason>` — the operator's text is NEVER echoed except a key id the store already knows; pinned by `operatorRequestUnknownVerbIsSkippedNotFatal`, which pastes a raw token where a key id belongs and asserts the report never carries it), the CLI output (pinned). The ruled initial-mint WARN (:214–:216) is UNCHANGED — the disclosed asymmetry stands; the request path logs the artifact PATH only.
4. **Atomic owner-only persistence:** `deleteIfExists(tmp)` → `FileChannel.open(tmp, {CREATE_NEW, WRITE}[, rw------- attrs on POSIX])` → write → `force(true)` → `setPosixFilePermissions(rw-------)` on POSIX → `Files.move(tmp, target, ATOMIC_MOVE)`; any failure → temp removed best-effort, `UncheckedIOException("failed to persist token store at …" / "failed to write initial token artifact at …")`, previous file byte-identical. Pinned: `persistIsAtomic` (no `.tmp` residue, reopen parses every row), `storeAndArtifactAreOwnerOnlyOnPosix` (POSIX-gated), `persistFailureLeavesPreviousStoreIntact` (the S-5c non-empty-directory blocker at the temp path — green on every platform).
5. **Thread safety unchanged:** all mutations on the existing `ReentrantLock` (re-entrant: `processOperatorRequests` → `rotate`/`revoke`/`mint` nest lawfully; `revoke` → `artifactCarriesDeadToken` → `validate` reads the map); `summaries()` reads the `ConcurrentHashMap`. Zero `synchronized`.
6. **Authorization two-layer:** the catch-all filter (P5) + `claimsFor(caller.keyId()).fullAccess()`; null identity → 403 (no NPE). Pinned: `forbiddenWhenCallerIsNotFullAccess`, `forbiddenWhenIdentityAbsent` (all three routes).
