# THE PELTON WORD — same-day execution card

## §1 The rule

THE WORD OUTRANKS EVERYTHING ON ARRIVAL. On results: classify A-CLEAN / B-MIXED / C-ADVERSE against the pre-staged map (the G-2 brief §1–§2) and execute the branch SAME-DAY. The call is scheduled IN ADVANCE (§2) so it is never a gate in front of the branch: on A it confirms the filing plan; on B it is where scope gets decided; on C it commissions the fallback — either way it is already on the calendar when the word lands.
