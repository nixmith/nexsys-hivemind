Flag every branch where counsel must decide.
2. **Article 14, as an operating procedure for a one-person manufacturer.** From 2026-09-11: exactly what event classes trigger the duty (actively exploited vulnerability — the definition; severe incident having an impact on the security of the product — the definition), the clocks, the CONTENT of each submission (early warning, notification, final report — list the fields the Regulation names), the channel (the Single Reporting Platform; which CSIRT — the main-establishment rule and what it resolves to for a manufacturer with NO Union establishment; ENISA's role), the user-notification duty (Art. 14(8)-class: informing impacted users, and corrective measures), and the voluntary reporting path (Art. 15). Then write it as a 1-page RUNBOOK DRAFT: who decides it is reportable, what artifacts are pulled, what is filed when. Name what does NOT exist yet and would be needed (a security contact address, an advisory page, an account on the platform when it opens).
