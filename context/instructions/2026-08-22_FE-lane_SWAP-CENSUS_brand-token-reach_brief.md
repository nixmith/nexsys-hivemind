**§2 The classification.** A table: file:line · the matched text · IN (renders the product name to a human — renames at the flip) / OUT (a technical identifier that NEVER renames: the npm package name, `homesynapse.service`, API paths, the JPMS `com.homesynapse`, the `homesynapse` Linux user, repo/dir names, the D-1 DO-NOT-SAY sentences which keep their exact wording) / REACHED (already flows from `BRAND.productName` — no edit) · the reason in ≤ 12 words.
