# W-HIVE-1 — the hivemind token economy (read-only measurement + proposal lane)

## 0. Why now (the executive reasoning — one paragraph, not a charter)

The project runs ~6–10 fresh sessions a week (hub, coder, FE, research). Every one re-reads a launch set before any work starts. The v54 rotation (2026-08-21) cut `pm-handoff.md` to ~43 KB; ONE DAY later it is **111,814 B** at `ee767de` (beats run 3–6 KB each and the frontmatter chain line — line 8, ONE line — re-states ~40 % of every block). `PROJECT_SNAPSHOT.md` 8,805 B carries a seven-segment chain whose body goes stale within a beat. `coder-handoff.md` 23,120 B duplicates its entries in its `last-verified:` chain. `coder-lessons.md` 32,153 B rotates by month, never by size. The v56 hub prompt is 24,852 B (the v55 prompt was 14,128 B). The auto-loaded role skills are the largest single reads: `project-manager/SKILL.md` **53,020 B** (its masthead is a rule register inside an HTML comment), `coder/SKILL.md` 35,667 B, `nexsys-skills/orchestrators/nexsys-frontend/SKILL.md` 41,636 B. A hub launch today is plausibly **≥ 120 KB** before its first act; halving it is the cheapest capability gain on the board and compounds through the Nov-25 runway. This is the right week: the core lanes are CI-gated and the hardware leg is on the cards, so a read-only lane costs the hub only its intake audit.
