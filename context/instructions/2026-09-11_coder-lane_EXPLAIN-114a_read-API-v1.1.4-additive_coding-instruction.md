## §1 What this implements
The hero design (`design/hero-v1/SPEC.md` §6) names nine sentences the dashboard cannot say until Core carries a key. Four of them need nothing the log does not already hold: the trigger's firing value is in the triggering `state_changed`/`state_reported` event the run's correlation already contains; the instant an action settled or confirmed is the timestamp of the `command_result`/`state_confirmed` event `deriveOutcome` already matches; a stable key for a definition is the `definitionHash` every `automation_triggered` event already carries; and the instant an automation was auto-disabled is the timestamp of the `automation_disabled` event the failure governor already emits. A fifth, the `FIRED_CONFIRMED` verdict, is the growth path `StandardExplanationService`'s own javadoc names for the DP-B2 clean-success case. This WU adds those keys to the explain reads, additively, as v1.1.4. The keys that need new recording or a new store read (`parentRunId`, condition text, the correlation-independent trigger lookup, per-permit trigger refs) are 114b and 114c.

- **DP-4 — `FIRED_CONFIRMED` replaces the DP-B2 inference for the clean-success case only.** `NEVER_TRIGGERED` with `lastRelevantRunId` null (genuinely never ran) is unchanged. The enum grows at the end. The current dashboard will render the new value through its unknown-verdict path until HERO-1b lands its row; report in §3 exactly what `WhyNotView.tsx` does with an unknown verdict at your HEAD, read-only.
- **DP-5 — `definitionKey` on the non-firing read and the list reads.** `DefinitionHashes` (`core/automation/.../DefinitionHashes.java`) computes the SHA-256 hex the engine stamps on `automation_triggered` (`RunContext.definitionHash()` `:26`, `:62`, `:79`; stamped at `StandardRunManager:649`). The runs list is built from `automation_completed`, which may not carry the hash: serve it there only if it does; otherwise leave the row out and declare it.
- **DP-6 — `disabledReason` for configuration-disabled** defaults to the literal `"configuration"`; if the definition carries a better-grounded value, use it and cite the field.
- **DP-7 — no `EventStore` by-id read in this WU.** `EventStore.java` has no `readById` (`:55–:153`: `readFrom`, `readBySubject`, `readByCorrelation`, `readByType`, `readByTimeRange`, `latestPosition`).
