## §1 What this implements
**The design problem.** Every beat re-writes four capped regions by hand (the chain ≤ 3,000 B, a beat block ≤ 2,500 B, the snapshot ≤ 3,500 B with a ≤ 2 KB digest, the brief ≤ 12,288 B with a ≤ 2 KB §DIGEST). v98 measured thirteen assert trips before any write, eleven of them on byte caps — a third of the window's calls spent fitting prose to a ceiling. The fix is generation: the volatile FACTS live in one small state file the hub edits; the prose SKELETON lives in a template; a renderer fills the template, asserts the caps, and writes the regions by the same guarded anchors the splice library already uses. The caps are then met or refused in one call, before any byte, with the number named.

**U1 — the state file, the templates, the renderer, the fixture (the gate).** (a) `context/status/state.yaml`, written BY HAND from the two live regions at your start sha: the shas (`core`, `bench`, `docs`, `skills`, `hivemind`), the Pi (`running`, `target`, `target_by`), the counter, the fleet (`registry`, `on_air`), the lanes (a list: `name`, `state`, `next`), the words (`given`, `open`), the week (a list of day rows), the dates, the next acts (a list), the open-risks line, and `notes:` — an ordered list of the digest's narrative sentences that are new each beat and belong to no field. ## §4 What to watch out for
- **Encoding and line ends.** The regions carry `—`, `·`, `≈`, `≤`, `→` and backticks: read and write `encoding="utf-8"`; write with `newline="\n"` (Git Bash on Windows would otherwise give CRLF and the byte gate fails for the wrong reason). Byte equality is tested on `str.encode("utf-8")`, never on `len(str)`.
- **The anchors.** The snapshot digest is `## The digest` to the end of file (the file ends with one newline — keep it). The brief's §DIGEST is `## §DIGEST` to the line before `## §NEXT`. Both appear exactly once; assert the count before any read of the region (the library's `once()` discipline).
- **YAML scalars.** Values hold `:`, backticks, `**`, `#` and `|` — quote every string with double quotes and escape inner double quotes; `yaml.safe_load` must round-trip (a test asserts it). No anchors, no flow style, no multi-line scalars — the hub edits this file by hand at every beat and reads it back by eye.
- **The fixture is frozen at your start sha**, not at `375592a` if the hub landed a beat in between: copy the regions with `git show <start-sha>:<path>`, never from a chat card or this file.
- **No byte of the live spine changes.** Your `--check` reads the live files; your `--write` and `beat()` tests run on `tempfile` copies. Before `RETURNED`, run `git --no-optional-locks status --porcelain` and confirm every row is `??` and in §3.
- **The caps are the library's constants** (`:19`), imported; `DIGEST_CAP = 2048` is the one new number (W-HIVE-1 P9; the brief's §DIGEST carries the same ceiling in its heading).
- **`beat()` keeps the law.** Every assert and cap before the first byte; the census computed from porcelain inside; the trailer grep on every text it writes; a failed assert leaves every file unchanged (the test's fourth case proves it by md5).
- **Time.** Writing the state file by hand from the two regions is the slow step (≈ 40 fields) — do it first, in one sitting, and run `--check` as soon as the templates exist; a `DIFF` names the first differing byte offset, not the whole region.
