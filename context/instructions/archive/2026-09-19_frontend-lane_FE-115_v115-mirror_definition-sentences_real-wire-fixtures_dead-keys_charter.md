## §4 What to watch out for
- `definitionSentence` is the ONLY place a condition definition becomes words; the catalog holds every word; the function is pure (no time, no state) and total (every input returns a string).
- The `children` recursion: `not` has one child; `and`/`or` have ≥ 2 in practice — render what the wire carries (0 children → the keyed "an empty group" sentence), never assume the arity.
- `above`/`below` are numbers on the wire (`Double`), `after`/`before` strings; a `value` may be a string that looks numeric — render as recorded, never coerce.
- The mock must stay a pre-v1.1.4 hub in ONE scenario (`legacy-hub`) so the absent-key arm keeps a reachable state.
- FE-114's fixtures-fold rule: a real-payload fixture's body is never edited; a whitespace change is a new fixture.
- Scripts over ~15 lines are written with the Write tool and run by path.
