# The measurement record

**How a row is filled.** The lane or the operator that reads the instrument fills `Value`, `Instrument (artifact · field)`, `Date (CT)`, `At (sha / run)`; the hub fills `Decides` at charter time and never edits a filled value. A value that a later reading contradicts gets a new row with the same prefix and the next number; the old row stays.
