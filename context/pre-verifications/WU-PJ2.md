## §2 The fork the instruction cannot settle alone (H10; the rec stands by silence past Mon 2026-09-28; `PJ2:` is the word)
**Question:** how is the window OPENED once the key is retired?
- **(a) `endpoint` — REC.** `POST /api/v1/integrations/zigbee/permit-join` `{ "duration_s": 1–254, "reason": "<free text, ≤ 120 chars>" }` on the existing bearer-token API (full-access token; `RestFilters`' filter chain), returning the window's `opens_at`/`closes_at`; the adapter emits `permit_join_opened` (duration, reason, actor) and `permit_join_closed` (elapsed | reopened | shutdown) as NEW event types by the contract's additive path; the key `permit_join_duration` is REMOVED from the schema (a boot with the key present → one WARN `zigbee.permit_join_key_ignored` and NO window — the attestation's own red stays possible only if the window opens, so the WARN is the honest trace); boot never opens a window. Cost: one Java unit across `event-model` (2 records), `integration-zigbee` (the open path re-shaped; the close emitted from the deadline; the start-path call removed), `rest-api` (one endpoint) — ≈ 1 lane-day; a docs cycle for Doc 08's key (an AMD row) and the API doc's new route. Risk: the bench's onboarding cards and the operator's habit ("restart with the key") both change — every card that pairs a device must carry the POST (a bench CODE row: `bench.sh permit-join <s> "<reason>"`). Buys: the pilot's onboarding is a command with a reason in the record; A1 holds by construction; the key can never sit live for 21 h again.
- **(b) `admin-verb`** — the same events and the same key retirement, but the opener is a CLI/admin verb in the launcher (no REST route): cheaper (no `rest-api` change, no API doc), but a pilot's onboarding then needs shell access to the box — against `pilot-first`.
- **(c) `hold`** — leave the key; add only the events and the boot WARN (a key present at boot still opens the window, now with an event of record). Cheapest; A1 is then a detector, not a preventer; IR-63 stays half-open.
**Refutable-by:** the pilot onboarding flow the strategy pass rules Tuesday needing something other than an authenticated HTTP call (then (b)). **Blocking:** no — IR-56's shape (P4 sample 3, Monday) and IR-61's landing come first; PJ-2 is wk 10-05 → 10-12 in THE WEEKS AHEAD §2.
