# Edit-Procedure Register

## §1 — The three standing write laws (inherited by every row)

1. **Single spine-writer:** only the hub writes the spine; lanes write only their named return path plus their chartered writable tree; the lane commits NOTHING — the hub audits and orders census-exact commits; Nick executes commits and the mirror sync.
2. **The write route of record (remote sessions):** edit-in-container → `SendUserFile` → `device_commit_files` (mtime-guarded); lock-free porcelain spelled in full (`git --no-optional-locks status --porcelain`); the Filesystem-MCP surface has schema-failed at first probe four times running (v53 launch ×2, v54 beat 1, R-11 2026-08-18) — the bridge tools are the stable path.
3. **Delete nothing — rebuild-or-archive only:** in-tree `mv` to a sibling `archive/` (with an inline header recording source path + rotation date, per `context/handoff/archive/README.md`) is the only removal form; Nick's `git add -A` commits it as a rename.
