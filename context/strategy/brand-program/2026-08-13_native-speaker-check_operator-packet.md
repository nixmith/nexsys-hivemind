Name order is rotated per gig so no name reads as "the favorite." If a seventh cheap gig is easy: **Portuguese (Brazil)** with the gig-5 script.

## The gig brief (paste as the order description, verbatim — replace nothing)

> I'm evaluating candidate brand names for a smart-home product and need a native speaker's linguistic read. For EACH of the three names below, please answer in English:
>
> 1. Say the name aloud naturally. Write how you pronounced it (syllables, which syllable you stressed).
> 2. What are the FIRST three things (words, images, feelings) that come to mind? Be honest, not polite.
> 3. Does it look or sound like any word, phrase, name, or brand in your language — including slang, rude words, or curse words, even partial or "one letter away"? List anything, even borderline.
> 4. Rate 1–5: how comfortable would this feel as the name of a device/app in your home? (1 = uncomfortable/funny/odd, 5 = completely natural.)
> 5. Would anything make you hesitate to say this name aloud in front of your family or in a store? If yes, what?
>
> Names: [PASTE THE THREE NAMES FOR THIS GIG, ONE PER LINE]
>
> Please answer all five questions for each name separately. Short, honest answers are perfect.

⚠ Fill-in before posting: the `[PASTE THE THREE NAMES FOR THIS GIG…]` line is the ONLY placeholder — replace it with the three names from the table row, one per line, in the row's order.

## The NL addendum (gig 2 ONLY — append after the names)

> One extra question, for the third name only [VERDOMO — it is third in gig 2's order]: some non-Dutch colleagues thought it might echo a Dutch curse word. As a native speaker: does it? How strong is the association (none / mild-would-smile / clear-would-joke / strong-would-avoid)? Would it affect whether a Dutch household would buy a product with this name?

## What this packet deliberately does not do

No checker sees the company name, the parent name, the product's architecture, or which candidate leads. No gig is rushed (rush signals importance). No checker is asked to "approve" anything — they report readings; the ruling stays ours.
