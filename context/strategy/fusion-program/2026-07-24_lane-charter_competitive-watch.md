# Standing Lane Charter — Quarterly Competitive Watch (tripwire sweep)

## 1. Mission

Keep the strategy steered by current ground truth, not stale priors. Each run answers: **did any tripwire fire this quarter, and what decision does each delta touch?** The output is a decision-keyed delta return (the 2026-06-27 model), never a survey. Risk-2 of the fusion strategy (HA moving up-market) is the reason this lane exists; the standard-race tripwire is its highest-stakes row.

|---|---|---|---|
| T1 | Nabu Casa / Open Home Foundation enterprise or commercial-tier language | Nabu Casa job postings + pricing pages; OHF posts/annual "State of the Open Home" | Beachhead defensibility clock (risk-2); Phase-1 pace |

Standing sub-rule: a tripwire caught mid-quarter (by anyone, in any session) escalates immediately — the cadence is a floor, not a gate on escalation.

## 3. Method (each run)

1. Read the PRIOR run's return (run #1 reads the 2026-06-27 currency return) — the delta is against IT, never re-derived from scratch.
2. Sweep T1–T7 against primary sources; date every observation; tag every claim.
3. Rank findings by decision impact (the §0-decisions-first format); each finding names the artifact it amends (positioning copy · phase plan · FQ-5 order · Matter program · thesis falsifiers).
4. Explicitly record NON-fired tripwires ("checked, quiet, evidence") — silence must be evidenced, not assumed (the vacuous-VERIFY discipline).
5. Return the ONE file; the hub audits two-layer and folds.

## 4. Done-when (per run)

All seven tripwires evidenced fired-or-quiet · deltas decision-keyed and ranked · the return audited · escalations (if any) in Nick's hands. Sized: one research session per quarter. Runs scheduled ~Oct 2026 → ~Jan 2027 → ~Apr 2027 → onward; each run's last act is to confirm the next run's date with the hub.
